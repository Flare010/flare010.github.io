Das Projekt

VARO, aber kompakt.

FLARE010 ist eine kurze, intensive Vanilla-Hardcore-PvP-Runde, angelehnt an das originale deutsche VARO-Format.

💀

Nur ein Leben

Stirbst du, ist dein aktives Spiel vorbei. Es gibt keine zweite Chance.

🌍

Die Border schrumpft

Die World Border wird immer kleiner und zwingt die Spieler nach und nach näher zusammen.

⚔️

Pure Vanilla

Keine Mods und keine spielverändernden Plugins. Minecraft Java Edition, PvP und dein eigenes Können.

Aktueller Stand

Die Plätze werden knapp.

Die Teilnahme ist auf 20 Spieler begrenzt. Ein Bewerbungsticket entspricht einem reservierten Teilnehmerplatz.

-- von 20 Plätzen--%
-- / 20Plätze vergeben
Ablauf

So läuft FLARE010 ab.

Das Event ist bewusst auf wenige Stunden ausgelegt, damit die Runde intensiv bleibt.

Vorbereitungsphase

Zu Beginn gibt es eine Phase ohne PvP, in der du Ressourcen sammeln und dich auf die Runde vorbereiten kannst.

PvP beginnt

Nach der Vorbereitung ist Schluss mit sicherem Farmen. Ab jetzt kann jeder Kampf entscheidend sein.

Die Border schrumpft

Die World Border wird regelmäßig kleiner und bringt die verbleibenden Spieler immer näher zusammen.

Nur einer kann gewinnen

Wer am Ende noch lebt, hat FLARE010 überlebt.

FAQ

Häufige Fragen

Wann findet FLARE010 statt?

Aktuell ist noch keine weitere runde in Planung.

Wie viele Spieler können teilnehmen?

Es gibt insgesamt 20 Plätze. Sobald alle Plätze vergeben sind, sind keine weiteren Anmeldungen möglich.

Was passiert, wenn ich sterbe?

Dein aktives Spiel ist nach dem Tod vorbei. Du kannst anschließend als Zuschauer dabei bleiben.

Welche Version wird verwendet?

FLARE010 wird für Minecraft Java Edition 26.2 veranstaltet.

Wie kann ich mich anmelden?

Die Anmeldung erfolgt über das Discord-Ticketsystem. Eröffne dort ein Bewerbungsticket, solange noch Plätze frei sind.

Bereit?

Willst du dabei sein?

Die ersten -- Teilnehmer erhalten einen Platz. Weitere Informationen und die Bewerbung gibt es auf dem Discord-Server.
